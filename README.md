# Async Web Crawler

Учебный проект асинхронного веб-краулера на Python. Текущая версия реализует
первый этап: базовый HTTP-клиент с параллельной загрузкой страниц.

## Возможности Day 1

- конкурентная загрузка URL через `asyncio.gather`;
- ограничение конкурентности через `asyncio.Semaphore`;
- переиспользование одной `aiohttp.ClientSession` и пула соединений;
- отдельные таймауты подключения и чтения;
- обработка HTTP-ошибок, сетевых ошибок и таймаутов;
- логирование начала и результата каждого запроса;
- корректное закрытие HTTP-сессии;
- тесты без обращения к реальной сети.

## Установка

```bash
python -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

## Демонстрация

```bash
python -m src.main
```

Скрипт загружает шесть URL сначала конкурентно, затем последовательно и
выводит время выполнения и коэффициент ускорения.

## Тесты

```bash
python -m pytest -q
```
